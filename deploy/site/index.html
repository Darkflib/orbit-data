Why Orbit Data

A shared cache, with fair use in mind.

CelesTrak's usage policy sets fair-use limits for automated downloads. Orbit Data refreshes upstream data conservatively and makes the cached results available to Orbit, rather than asking every Orbit user to download them from CelesTrak.

This service is intended to remain online for the foreseeable future. Visit Orbit or browse the Orbit source code.
